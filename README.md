# ДЗЕРКАЛО · FP | Olena Usenko

Публічний тест «Наскільки ви з Оленою Усенко схожі?» у стилі фан-каналу **FP | Olena Usenko** ([@olenausenko_fan](https://t.me/olenausenko_fan)).

Фан проходить той самий тест, що й Олена, і отримує:

- **власний повний результат**, як у [mbti-alone](https://github.com/kiruhatko/mbti-alone): тип, 5 шкал, 19 граней, когнітивні функції, опис;
- **блок «Ти і Олена»**:
  - близькість у відсотках: 100 − середня різниця відсотків за 4 шкалами (E/I, S/N, T/F, J/P);
  - кожна шкала двома смужками: ти й Олена;
  - три найбільш схожі й три найбільш різні грані.

Межові шкали Олени (E/I 54/46, J/P 46/54) позначено «у Олени майже порівну». Сайт ніде не пише «ти такий самий тип, як Олена» лише через збіг літер: головна цифра — близькість. У швидкому тесті (30 тверджень) граней немає, а шкали позначено «орієнтовно».

Твердження й підрахунок не змінено: `src/data.js` і `src/core.js` байт у байт такі, як у mbti-alone, а `build.py` звіряє їхні SHA-256. Еталон Олени пораховано саме цим кодом, контрольна сума набору тверджень QH = 8547.

## Приватність

> Твої відповіді не залишають твій пристрій. Ми нічого не збираємо.

**Без мережі.**
- Уся сторінка — один файл `index.html`: стилі, код, шрифти й еталон Олени вшиті всередину.
- Жодних fetch/XHR, аналітики, пікселів, Google Fonts чи CDN.
- CSP `default-src 'none'` такі запити просто заблокувала б.
- Тест у Chrome перевіряє, що запитів 0.

**Відповіді фанів.**
- Зберігаються лише в `localStorage` цього браузера (ключ `fp-dzerkalo.v1`).
- Кнопка «Стерти мої відповіді» прибирає їх повністю.
- Полів для імені, пошти, віку й акаунтів немає (серед фанів багато неповнолітніх).
- «Поділитися» дає текст або картинку, намальовану на `canvas` прямо в браузері. На ній лише тип фана й близькість, без відсотків Олени.

**Дані Олени.**
- У репо лише `reference.json`: тип, назва типу, відсотки шкал і граней.
- Сирого файлу, часу проходження, браузера, часового поясу й відповідей по окремих твердженнях тут немає, і в історії комітів теж (`tests/privacy-check.sh`).
- Відповіді по окремих твердженнях додаються **лише за явною згодою Олени**: `node scripts/make-reference.mjs <сирий.json> --with-answers`. Тоді на сайті з'явиться «Ви однаково відповіли на N з 91» і три твердження, де ви найбільш схожі. Без цього прапорця їх на сайті немає взагалі.

## Збирання й перевірка

```bash
node scripts/make-reference.mjs ../private/olena.json   # сирий файл лежить ПОЗА репо; у репо — лише reference.json
python3 build.py                                          # src/ + fonts/ + reference.json → index.html
node tests/e2e.mjs                                        # телефон і ПК: повний і швидкий тест, 0 запитів, 0 порушень CSP, 0 помилок
node tests/olena.mjs ../private/olena.json                # тест «відповідями Олени» → ENTP-A і близькість 100 %
node tests/shots.mjs                                      # скріни для погодження + og.png
bash tests/privacy-check.sh ../private/olena.json         # уся історія git без сирих даних
```

GitHub Pages: гілка `main`, корінь (`/`).
